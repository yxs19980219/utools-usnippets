# uTools 模式库插件（Pattern Vault）

## Goal

面向开发者的 uTools 插件"模式库"。检索逻辑是 **场景 → 解法**：用户知道问题，查询怎么解决。沉淀"经过验证的解法"——代码模板、架构模式、算法套路、最佳实践，形态为**可复制的片段**与**可阅读的笔记**两类，统一纯文本存储。

## Background

- 用户消费心智：片段 = 复制用；笔记 = 阅读用（笔记的即时渲染编辑体验由二期 atomic 承担）。
- 全部决策经 brainstorm 收敛，见 Key Decisions。

## In Scope（一期 MVP）

- 三栏主窗口：左栏分类树 + 标签区（可手动折叠）、中栏记录列表（200px）、右栏详情/编辑区（打开即编辑）；顶部工具条（搜索框 / 新建 / 设置）；初始高度 700。
- 记录模型：标题 + 场景（备注，多行输入框）+ 多片段 tab 行（每片段独立语言、可增删/拖动排序/切换）+ 分类（唯一归属，自建，无初始集，未分类兜底）+ 多标签。
- 编辑：统一 CodeMirror 6；语言列表含 markdown（一期源码高亮编辑）；底部状态栏 = 语言选择器（切当前 tab 语言）+ 行数 + 保存状态。
- 新建：直接建空白记录（默认一个 js 片段）进编辑器，无对话框选项（masscode 式）。
- 复制：详情页复制按钮 + 代码块内复制按钮。
- 保存：自动保存（编辑防抖 1s 落库 + 状态栏"已保存✓"）。
- 图片（一期）：粘贴 → 附件落库（≤10M，`att://` 引用）+ 插入 `![](att://<id>)` 源码；就地渲染留二期。
- 检索：顶部搜索框过滤中栏列表（匹配标题/场景/标签/正文全文），选中出详情（方案 B，不切列表视图）。
- 列表项：类型图标（全 markdown 片段 = 笔记图标）+ 标题 + 场景首行摘要 + 语言徽标；排序 = 最近修改优先；hover 复制/更多；右键菜单 = 移动分类 / 删除 / 导出图片。
- 分类/标签管理：树底新建分类、右键改名/删除、记录拖拽移动分类；标签不做合并（删除重打）。
- 深色模式跟随 uTools（CSS prefers-color-scheme + isDarkColors）。
- JSON 导入导出（设置内按钮）。
- 设置：深色跟随、默认语言。
- 空状态引导文案；删除直接删（无回收站）。

## Out of Scope（二期及以后）

- atomic 集成（markdown 即时渲染编辑）、图片就地渲染、公式 KaTeX 渲染。
- 呼出即搜（uTools 独立搜索入口）、列表 hover 复制、快捷键/命令面板、编辑历史。
- 分享链接、多设备手动同步以外的机制、回收站。

## Key Decisions

- 技术栈：React 19 + Vite + TypeScript + shadcn/ui + Tailwind CSS + Zustand。
- UI 形态：MVP 以主窗口管理为主；呼出即搜后续。
- 布局：三栏静态，无自动栏数变换；左栏手动折叠；初始高度 700。
- 打开即编辑，无"编辑/预览"切换层；新建直接建（无对话框）。
- 组织体系：分类 = 用户自建语义分类（唯一归属、未分类兜底、零初始集），标签 = 语义交叉（多对多）；类型（片段/笔记）与语言不占分类位（图标/徽标/筛选器表达）。
- 存储：记录/分类存 utools.db 文档（用户内容，合规，随账号同步）；图片存 utools.db 附件（≤10M，不可覆盖更新，替换删旧建新），正文 `![](att://<id>)` 引用；数据一律纯文本，永不锁定。
- 一期编辑器统一 CM6；markdown 语言二期切 atomic 即时渲染。
- 搜索为主角，组织为配角：分类放错不影响任何查找（全文检索兜底）。

## Acceptance Criteria

- [ ] 新建记录直接进入编辑态，默认一个 js 片段，列表同步出现条目。
- [ ] 多片段 tab 行：可添加、切换、删除、拖动排序；底部语言选择器切换当前 tab 语言（含 markdown）。
- [ ] 编辑内容防抖 1s 自动落库，状态栏显示"已保存✓"；重启插件记录不丢。
- [ ] markdown 语言片段内粘贴图片：附件落库、正文插入 `![](att://<id>)`。
- [ ] 顶部搜索框输入即过滤中栏（标题/场景/标签/正文命中），选中显示详情。
- [ ] 分类可自建/改名/删除，记录唯一归属、可拖拽移动；未分类记录自动聚拢在"未分类"区。
- [ ] 标签可添加/删除，按标签点击筛选列表。
- [ ] 详情页与代码块内复制按钮可用；右键菜单含移动分类/删除/导出图片。
- [ ] 深色模式跟随 uTools 切换；JSON 导出/导入往返数据完整。
- [ ] 在 uTools 3 老内核（Chrome 88 级）下界面正常渲染（无 oklch 线框问题）。

## Technical Notes

- uTools 3 内核不支持 Chrome 111+ CSS 语法：vite 配 Lightning CSS 降级（targets chrome 88，cssMinify: false）。
- 发布版禁止外部网络资源：所有依赖（CM6、highlight.js 等）本地打包。
- preload 用 CommonJS、源码可读、最小权限暴露；`utools.db` 只存用户内容，缓存/状态用内存或 dbStorage。
- uTools API 具体签名以 utools-dev skill 的 references/utools-api.md 为准。

## Risks / Deferred

- atomic 二期集成是编辑器内核替换，一期需保证片段数据纯文本、编辑器封装解耦（二期换编辑器组件零数据迁移）。
- 附件不可覆盖更新：替换图片走删旧建新，需处理失败回滚。
- 自动保存与附件异步落库的顺序需保证一致性（先附件后正文或事务兜底）。
- 大图（>10M）粘贴需拦截提示。
