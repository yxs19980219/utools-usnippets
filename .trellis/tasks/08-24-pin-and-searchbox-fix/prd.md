# PRD —— 中栏置顶功能 + 主界面搜索框不显示修复

## 交付物 A：中栏右键菜单置顶功能

### 需求

1. 模式库中栏（ListPane）右键菜单新增「置顶 / 取消置顶」项（toggle）：
   - 未置顶 → 置顶（置顶时间戳 = 当前时间）
   - 已置顶 → 取消置顶
2. 可同时置顶多个记录；**后置顶的优先级更高**（列表排序时置顶组排最前，组内按置顶时间倒序：最先显示的最后置顶记录）
3. 置顶状态持久化（utools.db，随记录存储，跨设备同步）
4. 回收站视图不提供置顶项
5. 置顶项的视觉区分：**琥珀金色标题**（用户确认方案，非图标）；已置顶项无图标标记
6. **左侧文件夹（分类）同样支持置顶**（用户追加需求）：右键菜单 toggle、置顶组排最前且后置顶优先、未置顶按 order、置顶名称琥珀金色

### 验收标准

- [ ] 中栏右键菜单出现「置顶/取消置顶」项，文案随状态切换
- [ ] 置顶 2 条后：置顶项排在最前，且后置顶的排在前面（优先级正确）
- [ ] 取消其中一条：它回到未置顶组、按 updatedAt 排序位置
- [ ] 重启插件后置顶状态与排序不变（持久化）
- [ ] 旧数据（已存在的记录）无置顶字段也能正常加载、排序、置顶
- [ ] 回收站记录右键菜单无置顶项
- [ ] 搜索视图（片段搜索）排序不受影响或按相同规则（见设计说明）
- [ ] 置顶 + 搜索 / 收藏 / 分类等视图组合排序正确

## 交付物 B：主界面搜索框偶发不显示修复

### 背景（已初步定位根因）

`App.tsx` 的 `onPluginEnter` 回调里，进入主界面时立即 `setSubInput`（A）；
`SearchView.tsx` 的 mount effect 里 `setSubInput`、unmount cleanup 里 `removeSubInput`（B）。
搜索视图切回主界面时：回调 A 先设置输入框 → React 异步渲染 → SearchView unmount cleanup
执行 `removeSubInput()` → **把主界面刚设置的搜索框清掉** → 搜索框不显示（间歇性与 React
commit 时序相关）。

### 需求

1. 进入模式库主界面（pattern-vault）时顶部 uTools 子输入框必显（搜索模式库）
2. 进入片段搜索视图（pattern-vault-search）时显示搜索视图自己的子输入框
3. 两视图间往返切换：输入框始终正确显示、不残留、不丢失；focus 行为不变
4. 插件退出（onPluginOut）时移除输入框

### 验收标准

- [ ] 主界面进入 → 顶部出现搜索框
- [ ] 片段搜索视图 → 顶部出现搜索框
- [ ] “片段搜索 → 主界面”往返 ×10 → 搜索框每个状态都正确（无丢失/无双框）
- [ ] “主界面 → 片段搜索 → 主界面”再回搜索 → 依然正常（循环往复）
- [ ] 输入搜索词后退出插件重进：搜索词状态合理（主界面搜索态由 ui store 语义不变）
- [ ] 无控制台报错

## 影响面

- 数据模型：`PatternRecord` 新增可选字段 `pinnedAt: number | null`
- 涉及文件（预估）：`src/types.ts`、`src/lib/search.ts`（排序）、`src/stores/records.ts`（togglePin/归一化）、`src/components/ListPane.tsx`（菜单与图标）、`src/App.tsx`、`src/components/SearchView.tsx`（输入框收口）、`src/stores/ui.ts`（如需要）
