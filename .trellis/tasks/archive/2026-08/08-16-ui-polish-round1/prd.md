# PRD：UI 优化第一轮（窗口/图标/提示/复制入口 + 拉伸灰区 bug）

## 背景

用户实测反馈 7 个问题点，涉及窗口行为、布局 bug、图标与提示、复制入口收敛。

## 需求与验收标准

### 1. 窗口高度：不强制拉高

- 现状：`App.tsx` onPluginEnter 中调用 `ut.setExpendHeight?.(700)`，每次呼出把窗口强制拉到 700 高。
- 目标：删除该调用，保留 `plugin.json` 的 `height: 600`（uTools 默认宽 800 → 800×600）。用户手动拉伸后 uTools 记忆其尺寸，插件不再干预。
- 验收：呼出插件窗口高度为 600（或用户上次手动调整的尺寸），不再被强制到 700。

### 2. bug：拉伸窗口后内容区出现灰色不可输入区域

- 现状：用户拉伸窗口后，右半部分出现不可输入的灰色阴影（推断为 uTools 窗口背景露出，webview 尺寸与窗口不同步）。
- 排查结论（2026-08-16 实测）：删除 `setExpendHeight` 后仍复现；灰区出现后切换记录（编辑器重建）、拖动窗口微调、重新呼出插件**均无法恢复**。结合 CM6 内部为 flex 铺满布局（无 JS 测量宽度依赖）可判定：**webview 视口 bounds 已永久丢失同步**，属 uTools/Electron 基座层 bug（与 tauri#6927 等同类 issue 完全一致：窗口管理软件快速 resize 时 webview 尺寸不正确）。
- 处理：插件代码无法修复。已为用户提供：① 向 uTools 官方反馈（复现：平铺 WM 拉伸插件窗口）；② 变通：真正退出插件（Esc/点外部区域）后重进或重启 uTools。
- 验收（原始预期）：删除后拉伸窗口无灰区 → **标记为基座 bug，不在插件内修复**（需求 1 的删除保留，属正确行为）。

### 3. 笔记图标改为一页纸

- 现状：`ListPane.tsx` 列表项笔记用 `BookOpenIcon`（翻开的书本），新建菜单"笔记"同样。
- 目标：改用 `FileTextIcon`（带文字的一页纸，用户已确认）。
- 验收：列表项笔记、新建菜单"笔记"图标均为带文字的一页纸。

### 4. 新建后标题占位提示：浅灰、正常字重

- 现状：标题 input `placeholder="输入标题"` 样式为 `font-semibold text-muted-foreground/60`，用户反馈太深、与标题本身难区分。
- 目标：占位提示改为正常字重 + 更浅的灰色（正文风格），与标题输入区分明显。
- 验收：新建记录后标题栏显示浅灰色"输入标题"提示，字体不加粗。

### 5. 标题字号加大

- 现状：标题 input `text-base`（16px）。
- 目标：加大（`text-lg` 18px），与提示文字拉开层级。
- 验收：编辑区标题比正文明显更大。

### 6. 复制入口收敛 + 中栏简化

- 现状：复制入口共 4 处——① 中栏列表项 hover 复制按钮；② 列表项右键菜单"复制"；③ 编辑区标题栏复制按钮；④ 内容区 hover 复制按钮。
- 中栏列表项还常驻显示语言徽标/「笔记」文字徽标（badge，`meta.badge`），且片段的多子片段可能是不同语言，单一徽标有误导。
- 目标：
  - 删除 ①（中栏 hover 复制按钮）与 ④（内容区 hover 复制按钮）
  - 保留 ② 右键菜单"复制"与 ③ 标题栏复制
  - 中栏列表项删除文字徽标，仅保留类型图标（笔记=一页纸 / 片段=代码文件）
- 验收：中栏悬浮无复制按钮、无语言/笔记文字徽标；内容区无悬浮复制按钮；右键菜单与标题栏复制可用。

### 7. 侧边栏：区域固定 + 设置底部居中

- 现状：库/文件夹/标签共用一个滚动容器；设置按钮在底部左侧带 `border-t` 横线。
- 目标（用户确认）：库、文件夹、标签、设置四个区域各自固定布局；文件夹区域占中间空间（60%），标签区域在中间偏下位置（40%），内容溢出各自滚动；设置按钮居中显示、去掉横线。
- 验收：
  - 库区块固定顶部不滚动
  - 文件夹区块占中间 60% 空间，内容溢出滚动，标题固定
  - 标签区块占 40%（垂直中下位置，不贴底），内容溢出滚动，标题固定
  - 设置按钮在底部居中，无分割线

### 8. markdown 标题字号放大（用户第二轮反馈）

- 现状：atomic 编辑器标题偏小（h1 仅 1.35em，h4 与正文同大，h5/h6 小于正文）。
- 目标：放大标题层级（h1 1.6em / h2 1.35em / h3 1.2em / h4 1.1em / h5 1em / h6 0.9em），保持 weight/letter-spacing/uppercase 等其余样式。
- 实现：globals.css 中 `.atomic-cm-editor .cm-line.cm-atomic-hN` 前缀覆盖（特异性 0,3,0 压过懒加载的 atomic 样式表）。
- 验收：笔记（markdown）中各级标题明显大于正文，层级清晰。

## 非目标

- 不改数据模型、不改存储、不改搜索逻辑。
- 不调整窗口宽度（uTools 无 width 配置项，默认 800）。
- 不动列表项右键菜单的其他项（收藏/移动分类/导出图片/回收站）。
