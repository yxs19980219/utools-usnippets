# UI 增强：图标/文件夹右键/标签删除/搜索视图细节

## Goal

对既有三栏主界面 + 片段搜索视图做 5 处 UI 与交互增强，全部为纯前端改动。

## Requirements

### 1. 中栏列表项图标改为 `< >` 代码样式
- 现状：`ListPane` 列表项片段用 `FileCode2Icon`（文件+角标），笔记用 `FileTextIcon`。
- 目标：片段图标改为 lucide `Code2Icon`（`<>` 样式），笔记图标不变。
- 范围：列表项图标 + 顶部"新建片段"菜单项图标，两处统一。

### 2. 文件夹右键菜单（左侧边栏）
- 现状：`Sidebar` 文件夹已有 ContextMenu，但**点不出**——根因是 `NavRow` 组件未透传 `onContextMenu`，Radix `ContextMenuTrigger asChild` 注入的事件被丢弃（ListPane/FragmentTabs 用原生 div 所以正常）。
- 目标（右键菜单三项）：
  1. **重命名**（已有，保留）
  2. **默认片段语言**（新增）：子菜单列出 20 种语言；设置后，在该文件夹视图下点击新建片段 → 片段自动归入该文件夹 + 语言用该文件夹的默认语言（未设置则用全局默认语言）
  3. **删除**（行为变更）：删除分类 = 其下所有记录**移入回收站**（软删除，可在回收站恢复），非当前"移入未分类"。须有确认提醒，提示分类名 + 受影响记录数。

### 3. 标签右键菜单：删除
- 现状：标签云无右键菜单。
- 目标：参考 masscode，标签项右键 → "删除"，从**所有记录移除该标签**（非删除记录）。删除前弹出确认框，提示标签名 + 受影响记录数；若当前视图正筛选中该标签，删除后切回"所有"。

### 4. 搜索视图快捷键提示样式
- 现状：`ShortcutBadge` 为 kbd 小徽标（9px、带边框背景）。
- 目标：改为**纯文字、字号更大、垂直居中**，去掉边框/背景样式。

### 5. 搜索视图标题右侧归属文件夹
- 现状：仅有所属文件夹的记录显示 `FolderIcon + 名称`；收件箱（无所属文件夹）不显示。
- 目标：所有记录都显示归属信息——有文件夹：`FolderIcon + 文件夹名`（保留现状）；收件箱：**黄色文件夹图标 + "收件箱"**。备注（scenario）保持现状不变。

## Acceptance Criteria

- [ ] 中栏列表项与"新建片段"菜单图标为 `<>`（Code2）样式，笔记图标仍为文件图标
- [ ] 左侧边栏文件夹行右键能弹出菜单（修复透传），含 重命名 / 默认片段语言 / 删除
- [ ] 文件夹设置默认语言后，在该文件夹视图下新建片段：自动归入该文件夹，语言为该语言
- [ ] 删除文件夹时弹确认框（显示分类名 + 记录数），确认后其下记录全部进入回收站，分类被删除
- [ ] 标签右键"删除"弹确认框（显示标签 + 记录数），确认后从所有记录移除该标签
- [ ] 搜索视图快捷键为纯文字、更大、居中，无边框徽标样式
- [ ] 搜索视图每行标题右侧：有文件夹 → 文件夹名；收件箱 → 黄色文件夹图标 + "收件箱"；备注显示不变
- [ ] 现有功能无回归（新建/编辑/搜索/拖拽/导入导出）

## Notes

- 语言来源：`src/lib/languages.ts` 的 `LANGUAGES`（20 种，含 label/value）
- 分类默认语言存储：Category 文档新增可选字段 `defaultLanguage?: string`（跟随 db 同步，合规）
- 不改动：标签合并、文件夹嵌套、UI 设计体系（沿用现有 shadcn/Tailwind 变量）
